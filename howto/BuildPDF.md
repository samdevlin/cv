# Build a PDF

There are two ways to do this. A github action has been created using md2pdf, run it in the actions tab and click the generated download link. I haven't added any styling to this action though, and the default styling is not great.

However, I would recommend using [md-to-pdf](https://github.com/simonhaenisch/md-to-pdf#readme) locally as the default styling is nicer.
