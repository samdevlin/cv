# Build a PDF

There are two ways to do this. A github action has been created using md2pdf, run it in the actions tab and click the generated download link. I have added the same styling as the manual approach described below, so this is now the easiest way.

You can also build a PDF using [md-to-pdf](https://github.com/simonhaenisch/md-to-pdf#readme) locally. The default styling is nice, seems to work okay but the repo doesn't seem to be actively maintained.
